# 🌦️ صحنه‌های آب‌وهوا (Weather Scenes)

هر صحنه یک تصویر WebP برای روز و یکی برای شب است: `res/drawable-nodpi/scene_<حالت>_<day|night>.webp` (۱۱۰۴×۶۶۰).
`SceneKind` در `ui/WeatherScene.kt` حالت را از گزارش هوا انتخاب می‌کند و ذره‌های زنده را روی تصویر می‌اندازد.
در فارسی (RTL) تصویر آینه می‌شود تا خورشید/ماه روبه‌روی ستون متن بماند.

| صحنه | کدهای WMO / شرط |
|---|---|
| clear | 0، 1 |
| partly_cloudy | 2 |
| cloudy | 3 با پوشش ابر < ۸۰٪ |
| overcast | 3 با پوشش ابر ≥ ۸۰٪ (و کدهای ناشناخته) |
| fog | 45، 48 |
| drizzle | 51، 53، 55، 61 |
| rain | 63، 80، 81 |
| heavy_rain | 65، 82 |
| thunderstorm | 95 |
| hail | 96، 99 (با فلش رعد) |
| sleet | 56، 57، 66، 67 |
| snow | 71، 73، 77، 85 |
| blizzard | 75، 86 |
| windy | آسمان خشک (صاف/نیمه‌ابری/ابری) و باد ≥ ۳۵ km/h |
| dust | آسمان خشک و گردوغبار CAMS ≥ ۱۲۰ µg/m³ |
| hot | آسمان صاف، روز، دما ≥ ۳۸°C (شب = clear) |

ذره‌ها: باران، برف، تگرگ، ستارهٔ چشمک‌زن (شب)، رگه‌های باد، ذرات غبار و فلش رعد.
تنظیمات ← «صحنهٔ زندهٔ آسمون» خاموش = گرادیان ساده؛ «انیمیشن‌ها» خاموش = ذره‌ها ثابت.
