# 📋 پوشش مشخصات اپلیکیشن هواشناسی حرفه‌ای — iWeather

وضعیت هر بخش از مشخصات ۲۰بخشی، صادقانه و بدون اغراق:

- ✅ **ساخته شده** (به دادهٔ واقعی یا منطق معتبر روی دستگاه متصل است)
- 🔜 **در نقشهٔ راه** (منبع دادهٔ معتبر دارد و در نسخهٔ بعد می‌آید)
- ⛔ **بدون منبع معتبر** (با منابع رایگان فعلی دادهٔ قابل اتکا ندارد؛ عمداً ساخته نشده تا دادهٔ ساختگی نمایش داده نشود)

آخرین به‌روزرسانی: نسخهٔ ۱٫۴٫۰ — استایل Luna، ۱۶ صحنهٔ آب‌وهوا، شهرهای ذخیره‌شده و پیام صبحگاهی (جزئیات: CHANGELOG-1.4.0.md). قبلی: نسخهٔ ۱٫۳٫۰ — بازطراحی ظاهری Eclipse (کارت‌های شیشه‌ای با حاشیهٔ نورانی، هیروی سلام/نقل‌قول/دمای نمایشی، ناوبری کپسولی شناور، کاشی‌های سریع) و مدل حرکت طبیعی آسمون زنده (رانش یک‌جهتهٔ ابرها با سرعت ثابت و وابسته به باد واقعی، بدون نوسان و تپش). تغییر داده/منبع در این نسخه نیست؛ چندمنبعی‌شدن (مدل‌های ECMWF/ICON/GFS و MET Norway) در نقشهٔ راه می‌ماند.

## اصول رعایت‌شده (از خود مشخصات)

1. هیچ قابلیتی نمایشی نیست؛ هر کارت به دادهٔ واقعی API یا محاسبهٔ معتبر روی دستگاه وصل است.
2. هر جا منبع معتبر نیست، بالا صریحاً ⛔ خورده و در اپ هم دادهٔ ساختگی نمایش داده نمی‌شود.
3. لایهٔ داده (Provider) از UI جداست؛ افزودن منبع دوم بدون تغییر UI ممکن است.
4. دادهٔ کش‌شده همیشه با برچسب و زمان مشخص است.
