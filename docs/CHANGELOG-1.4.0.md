# iWeather 1.4.0 — تغییرات

## 🎨 رابط
- بازطراحی کامل صفحهٔ اصلی با استایل Luna: هیروی تصویری، کارت آسایش، چهار کاشی، منحنی دما، کارت‌های میان‌بر، نوار ناوبری شناور
- ۳۱ صحنهٔ روز/شب برای ۱۶ حالت آب‌وهوا + ذره‌های زندهٔ Canvas (جایگزین Living Sky قدیمی)
- تنظیمات، ویجت‌ها و صفحهٔ تنظیم ویجت هم‌رنگ با تم جدید؛ آیکون جدید اپ (ماه + ابر + جرقه، با لایهٔ monochrome)
- نام اپ: **iWeather** (پکیج/`applicationId` = `com.pishi.iweather`)

## ✨ قابلیت‌های جدید
- شهرهای ذخیره‌شده (تا ۱۲) با دما/وضعیت آخرین دادهٔ هر شهر؛ کش آفلاین برای هر شهر (حداکثر ۱۶، قدیمی‌ترین حذف می‌شه)
- پیام صبحگاهی (اختیاری) با ساعت دلخواه
- امتیاز «آسایش بیرون»
- منحنی دمای ۲۴/۴۸ ساعته با دمای حس‌شده
- افزودن صحنهٔ «گردوخاک»، «باد»، «گرما» بر اساس داده (CAMS، سرعت باد، دما)
