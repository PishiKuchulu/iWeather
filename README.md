# 🌤️ iWeather

**اپلیکیشن آب‌وهوای فارسی/انگلیسی با صحنه‌های زندهٔ آسمون — استایل شیشه‌ای «Luna».**

An Android weather app (Kotlin · Jetpack Compose · Material 3) with 16 hand-built day/night sky scenes, live particles (rain, snow, hail, stars, lightning), an on-device "smart layer" (comfort score, what-to-wear, alerts, activity scores), widgets, notifications and a Persian-first UI with the Jalali calendar. Free Open-Meteo data — no API key.

> نام قبلی پروژه «آسمون / Asmoon» بود؛ از نسخهٔ ۱٫۴٫۰ اسمش **iWeather** و `applicationId` شد `com.pishi.iweather`
> (روی گوشی به‌صورت یک اپ جدید نصب می‌شه؛ اگه می‌خوای آپدیتِ روی نسخهٔ قدیمی باشه، `applicationId` رو توی `app/build.gradle.kts` برگردون).

## ✨ چی داره؟

### 🌙 صفحهٔ اصلی (استایل Luna)
- **هیرو:** صحنهٔ تصویری روز/شب برای وضعیت فعلی + سلام وابسته به ساعت، نام شهر (با ★ ذخیره)، «حال‌وهوای امروز» و دکمهٔ «موقعیت من»
- **کارت آسایش:** حلقهٔ ۰–۱۰۰ «آسایش بیرون» (دمای حس‌شده، بارش، باد، کیفیت هوا) با دمای فعلی وسطش
- **چهار کاشی:** رطوبت، باد، فشار (با روند ↗↘) و دید افقی
- **منحنی دما:** ۲۴ یا ۴۸ ساعت، با دمای حس‌شده، میله‌های احتمال بارش و راهنمای رنگی (راست‌به‌چپ در فارسی)
- **دو کارت میان‌بر:** «چی بپوشم؟» و «بینش هوشمند» (اسکرول به بخش مربوط)
- هشدارها، ساعتی ۴۸ ساعته، امتیاز فعالیت‌ها، جزئیات، کیفیت هوا (CAMS)، خورشید و ماه، پیش‌بینی ۱۶ روزه
- نوار ناوبری شناور: خانه / جستجو / شهرها / تنظیمات

### 🌦️ ۱۶ حالت آب‌وهوا × روز/شب
صاف، نیمه‌ابری، ابری، تمام‌ابری، مه، نم‌نم، باران، بارش سنگین، رعدوبرق، تگرگ، برف‌وباران، برف، کولاک، باد، گردوخاک، گرما (فقط روز).
نگاشت کدهای WMO → صحنه: [docs/WEATHER-SCENES.md](docs/WEATHER-SCENES.md)

### 🧠 لایهٔ هوشمند (روی دستگاه، بدون AI و بدون هزینه)
حال‌وهوای امروز · چی بپوشم · هشدارها (چتر، UV، باد، گرما/سرما، گردوغبار، AQI) · پنجرهٔ بارش · امتیاز دویدن/پیاده‌روی/عکاسی/رانندگی/دوچرخه/کوهنوردی

### 🆕 نسخهٔ ۱٫۴٫۰
- **شهرهای ذخیره‌شده** (تا ۱۲ شهر): ★ روی هیرو، فهرست با دما و وضعیت هر شهر در برگهٔ «شهرها»، حافظهٔ آفلاین برای هر شهر
- **پیام صبحگاهی** (اختیاری): هر روز در ساعت دلخواه — وضعیت هوا، چی بپوشی، بازهٔ بارش
- **موقعیت دقیق‌تر:** مکان تازه (نه آخرین مکانِ قدیمی) + نام واقعی شهر با Geocoder
- **دکمهٔ برگشت** درست کار می‌کنه (بستن جستجو/شهرها/تنظیمات به‌جای خروج از اپ)
- **Edge-to-edge** و رعایت نوار وضعیت/ناوبری روی همهٔ نسخه‌های اندروید
- فهرست کامل اصلاح‌ها: [docs/CHANGELOG-1.4.0.md](docs/CHANGELOG-1.4.0.md)

### قبلی‌ها
ساعتی ۴۸ ساعته، ۱۶ روزه، CAMS، نجوم (ماه/گرگ‌ومیش)، حافظهٔ آفلاین (۱٫۱)؛ دوزبانه، تنظیمات کامل، ویجت‌های ۲×۲/۴×۲/۴×۴، اعلان هشدار (۱٫۲)؛ شیشه‌ای و حرکت طبیعی (۱٫۳). وضعیت پوشش مشخصات: [docs/SPEC-COVERAGE.md](docs/SPEC-COVERAGE.md)

## 🔌 منبع داده
[Open-Meteo](https://open-meteo.com) — Forecast، Geocoding و Air Quality؛ بدون API Key و بدون ثبت‌نام.

## 🛠️ تکنولوژی
- Kotlin 2.0 + Jetpack Compose (Material 3)، WorkManager برای ویجت/اعلان‌ها
- بدون کتابخونهٔ شبکهٔ سنگین — `HttpURLConnection` + `org.json`
- صحنه‌ها: ۳۱ تصویر WebP در `res/drawable-nodpi` (۶۰۰ کیلوبایت در مجموع) + ذره‌های زنده با Canvas
- minSdk 26، targetSdk 35

## 🚀 بیلد
```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/
```
یا پوش به GitHub؛ اکشن `Build APK` خودش APK دیباگ رو می‌سازه.

## 📁 ساختار
```
app/src/main/java/com/pishi/iweather/
├── MainActivity.kt           # edge-to-edge، موقعیت، مجوز اعلان
├── data/                     # Open-Meteo، مدل‌ها، کش (آخرین + هر شهر)، شهرهای ذخیره‌شده
├── ui/
│   ├── IWeatherViewModel.kt  # state، لغو درخواست قدیمی، شهرهای ذخیره‌شده
│   ├── HomeScreen.kt         # صفحهٔ اصلی Luna + جستجو + شهرها
│   ├── HomeSections.kt       # هوا/خورشید و ماه/۱۶ روزه/حلقهٔ امتیاز
│   ├── LunaComponents.kt     # آیکون‌های خطی، حلقه، دکمه‌ها، نوار ناوبری
│   ├── WeatherScene.kt       # نگاشت هوا → صحنه + ذره‌های زنده
│   ├── SettingsScreen.kt
│   └── theme/Theme.kt        # پالت Luna + lunaGlass()
├── notify/                   # هشدارها + پیام صبحگاهی (WorkManager)
├── widget/                   # ویجت‌ها
└── util/                     # شمسی، اعداد، بینش‌ها، رشته‌ها، نجوم
```
